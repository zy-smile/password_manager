# 个人助手（Personal Assistant）

基于 Flutter 的本地个人助手，当前版本为 1.0.1，包含密码箱、衣橱管理和设置中心。所有业务数据保存在设备本地，当前版本不提供云同步。

## 功能

### 密码箱

- 主密码首次设置、解锁和修改：新密码至少 8 位且包含数字；错误 5 次后冷却 30 秒。
- 随机 256 位数据密钥加密用户名、密码和备注；主密码通过 PBKDF2-SHA256（150000 次）派生包装密钥，以 AES-256-GCM 保护数据密钥。
- 修改主密码只更新一条安全存储记录，不重新加密账号数据库。旧版 v2 认证在主密码解锁时自动升级，保留原数据密钥。
- 生物识别可选：通过系统验证后读取安全存储中的数据密钥。
- 账号增删改查、标题/网站/用户名搜索、默认分类筛选和收藏优先排序。
- 查看或复制密码需要再次验证；复制内容 30 秒后仅在剪贴板内容未改变时清空。
- 安全随机密码生成器和强度提示。

### 锁定

- 主密码保护整个应用，包括衣橱。
- 手动立即锁定、前台闲置锁定、后台超时返回锁定。
- 时间选项：立即（离开应用时）、1/5/10/30 分钟。
- 锁定销毁整个导航树和敏感编辑页面，清除密码箱明文缓存；异步加载结果不能在锁定后写回。
- Android 禁止截图/录屏，并保护最近任务缩略图。

### 加密备份

- 新版 2.0 备份使用独立备份密码（至少 8 位），包含版本、算法、派生参数、随机盐、随机 IV 和认证密文。
- 支持分享加密文件、从系统文件选择器导入、恢复到其他设备。修改主密码不影响独立密码备份。
- 导入验证版本、派生参数、GCM 认证和全部账号结构；验证通过后在数据库事务内覆盖密码箱。
- 旧版 1.0 备份仍可在原保险箱密钥下恢复；旧格式本身不能通过相同主密码在新设备恢复。
- 备份仅包含密码箱账号，不包含衣服、照片、分类配置或应用设置。请将备份文件另存到应用外，并保存好备份密码。

### 衣橱

- 名称、分类、春夏秋冬多选、颜色、品牌、购买日期、备注和收藏。
- 拍照/相册选图，照片复制到应用文档目录。
- 关键字搜索、分类/季节筛选，总数及分类/季节统计。
- 衣服字段和照片明文存储；不参与密码箱加密备份。

## 技术与结构

实际使用 Flutter、Provider/ChangeNotifier、sqflite、sqflite_common_ffi、flutter_secure_storage、local_auth、encrypt、crypto、image_picker、file_picker 和 share_plus。

```text
lib/
  app/                  应用壳、会话锁定和导航
  core/                 加密、安全存储、数据库、主题、工具
  features/vault/       data/domain/presentation/backup
  features/wardrobe/    data/domain/presentation
  main.dart             初始化和依赖装配
test/                   核心逻辑和锁屏回归测试
```

密码箱 Provider 直接调用 Repository；UseCase 文件保留但未作为主调用链。衣橱 Provider 直接调用 DAO。当前采用模块化分层，不声称已完整实现 Clean Architecture。

数据库版本 3，单库 `password_vault.db`。新增模块需要注册数据表并编写版本迁移。只有密码箱敏感字段加密，标题、网站、分类和时间等元数据明文存储。

## 开发与构建

环境：Flutter 3.44 或更高、Dart 3.12 或更高；Android 构建需要 JDK 17 和 Android SDK。

```bash
flutter pub get
flutter analyze
flutter test
flutter run
flutter build apk --release
```

APK 默认位置：`build/app/outputs/flutter-apk/app-release.apk`。

当前 release 构建使用本机 debug keystore 签名，适用于安装测试；商店发布应配置自己的 release 签名，私钥和 `key.properties` 不提交到 Git。

Windows 的插件链接需要开发者模式或允许创建符号链接的权限。原生 SQLite 构建依赖 GitHub release 下载；网络失败时需恢复网络后重试，不能跳过测试并声称通过。

## 已知范围与待验证项

- Android 为本次 APK 构建目标；iOS 和桌面存在代码，仍需对应平台实机验证。Web 尚未适配 `dart:io` 和数据库路径。
- 自定义分类管理、手机号/邮箱独立字段、最近使用记录、衣橱备份、云同步、TOTP 尚未实现。
- 万条缓存搜索有回归测试；启动耗时、首次万条解密、真机解锁耗时和滚动帧率仍需设备性能测试。
- 生物识别、相机、文件选择与分享需要真机验收。
- 测试覆盖率未承诺达到 80%。
